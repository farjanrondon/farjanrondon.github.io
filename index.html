How fast does a fault need to be cleared?

A generator feeds the grid through two parallel lines, and a three-phase fault hits one of them. Move the clearing time and watch the rotor angle: clear the fault quickly and the machine swings back; wait too long and it loses synchronism.

MATLABPower flow and stability

Power flow and transient stability analysis

Reads a complete case from an Excel workbook (buses, lines, transformers and shunt elements), builds the Y-bus and solves the load flow with four methods. The DC solution can be used as the starting point for the iterative ones. The method with the lowest error then feeds a transient stability study: the network is expanded with the generators’ internal buses, Kron-reduced for the pre-fault, fault and post-fault states, and the swing equation is integrated for a line fault and clearing time chosen by the user.

  1. Excel case file
  2. Y-bus matrix
  3. Gauss-Seidel, Newton-Raphson, fast-decoupled, DC
  4. Lowest-error solution
  5. Kron reduction
  6. Swing equation with Heun or RK4
  7. Results back to Excel

For each method the output workbook holds bus voltages and angles, line flows and losses, and the system power balance.

Pythonpandas, NumPy

Power flow solver

The Python implementation of the load flow: Gauss-Seidel, Newton-Raphson, fast-decoupled and DC methods, with lines and off-nominal-tap transformers modeled as π-equivalents and loads modeled as ZIP (constant impedance, current and power). Each run saves a copy of the input workbook with the results, so different cases can be studied side by side.
